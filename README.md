The final project does branch off from what I had originally proposed but it still keepts its identity as a way to add events to your calendar.
At first I had planned to hard code an entire calendar that would only work by itself and woudn't be stored locally to anything. After learning about ICS files I decided to go a different route.
The way it works now is simple, there is a few lines you must fill in, a "event name", "start time", and "end time", with an optional description.
Once the user fills in all of the lines they press the button on the bottom and a ICS file is created with the information the user just filled out.
Once the user opens the ICS file, it should open their primary calendar app, and they should be able to extract the ICS file's information and automatically add the event to their Calendar.
One of the biggest uses outside of personal use is that you can create and event and ICS file for it, then if you have a group of people to send it to, you can send them the file, and they can automatically add it to their calendar so multiple people can mark that specific date.
